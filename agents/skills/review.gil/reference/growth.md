# Growth (lens expansion + harvest)

Load only when adding a lens or harvesting Assure lessons.

**New lens** only if: distinct signals, can't be a section of an existing `reference/*.md`, reusable ≥2 times, not language-named. Otherwise sparse-promote into `finish` / `tests` / `perf` / `security` / `legacy` / `quality`. Freeze `SKILL.md` unless the contract is wrong.

**Harvest:** stage in [`learning-log.md`](learning-log.md) → generalize → tag one primary lens → promote only when review judgment changes → drop the rest. Cap ~10 per event; leave the log empty; no rejects archive.

- Craft / ownership / types / seams / measured perf → `architecture` growth.
- Language-only → `$dev` → routed `{lang}-dev` `reference.md`.
- Findings judgment / merge-prep smells → matching lens ref.
- `finish` incident postures: one-line cues with remediation pointers, no craft dumps.

After store edits: `skill doctor`; `drift` → `skill backfill <name>` → `rcup`.
