# deep-modules

Axioms: [`axioms.md`](axioms.md). Terms: [`glossary.md`](glossary.md).

## Earn this branch

Dual ownership of one fact, passthrough bags, shallow multi-call husks, or a structural cleanup / deepen ask.

## Checklist

- Deletion-test candidates and thin re-export bags; one public name per schema/type; shared kernels import the owning module, not a re-export.
- Survey on ownership/seam failure signals, not metric smell counts; with many peers, infer canonical shape first (survey mode).
- Wrong-layer domain surfaces: relocate before deepening in place.
- Validate and run share one expansion path — dual expansion greenlights configs that fail later.
- One remaining wall-clock across fallbacks and pagination, passed down.
- Shared meters/policies: one construction home, explicit at the pipeline boundary; a discriminating test proves omission fails.
- Cut over only once the replacement owns the implementation one-way; reverse calls into the old home are dual ownership.
- Relocating a predicate: verify each call site's argument shape still matches what it inspects.
- Detect-and-persist in one critical section; check-then-act across suspension points is dual ownership of uniqueness.
- Freshness ≠ sync: never gate identity reload or capture visibility behind sync throttles.
- Quarantine a permanently invalid unit so sequential siblings proceed.
- Committed primary survives failed enrichment: nest enrichment status on the success value; never unwind the primary.
- On conflict revert to last-known-good; never mint a new identity and retry.
- Route keys are stale unless live state matches; on mismatch fall back to create/list shell.
- Two runtimes encoding one closed decision share one fixture corpus.
- Inject base dirs, clocks, storages — hardcoded paths / global stores force god-object orchestration.
- Extract domain math trapped in views/config structs into pure VOs before building views.
- Delivery modes deliver facts, never author schema — one construction path per derived fact (co-load `refactor-types`).
- Success-advertising side effects attach only after the durable op succeeds.
- Multi-step durable work returns committed | rejected | indeterminate; never swallow rollback failure (co-load `refactor-types`).

## Anti-patterns

- Dump modules of unrelated helpers; twin structs kept in sync; adapters growing domain branches; views housing domain geometry.
- Agentic pipelines: multi-hop husks re-summarizing intent; nested AST schemas where structured Markdown DTOs suffice.

## Sequencing

Small phases, validate each. Co-load `refactor-types` when closed sets sit on the same seams; `performance` only when a measured bottleneck drives a layout move.

## Done when

Deletion test / ownership / seams addressed; phases validated; residual dual ownership called out.
