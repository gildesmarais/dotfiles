# Growth (branch expansion + harvest)

Load only when adding an architecture branch or harvesting lessons. Staging/promote: `harvest/reference/distill.md`. Corpus: structural cuts only; survey lessons → `structure-survey.md` or [`glossary.md`](glossary.md).

## Branch expansion law

1. Refactor branches are only `refactor-<concern>`; never `refactor`, `refactor-misc`, `cleanup`, or language-named.
2. New branch only if: distinct signals; cannot be a section of an existing `reference/*.md`; reusable ≥2 times; language-free.
3. Adding one = one `## Pick branch` row + `reference/<branch>.md` with `## Done when`; never a new top-level skill.
4. Overlap: tree/snowflake → `structure-survey`; ownership/depth → `deep-modules`; type dual homes → `refactor-types`; serialize/shells → `refactor-boundaries`; measured speed → `performance`; GoF → `design-patterns`.
5. Stage in [`learning-log.md`](learning-log.md) → sparse-promote per distill → drop the rest. Edit the router only when the contract is wrong.
