# Growth (branch expansion + harvest)

Load only when adding an architecture branch or harvesting lessons. Staging/promote: `harvest/reference/distill.md`. Architecture corpus: structural cuts only (ownership, seams, types, measured perf); survey lessons → `structure-survey.md` or [`glossary.md`](glossary.md), never a new craft branch.

## Branch expansion law

1. Refactor branches are only `refactor-<concern>`; never `refactor`, `refactor-misc`, `cleanup`, or language-named (`refactor-rust`).
2. New branch only if all hold: distinct signals; cannot be a section of an existing `reference/*.md`; reusable ≥2 times; language-free. Reject third-party recipe dumps and craft branches duplicating survey discovery.
3. Adding one = one `## Pick branch` row + `reference/<branch>.md` with `## Done when`; never a new top-level skill. Discovery modes may be a `reference/*.md` + router contract without becoming a craft branch.
4. Overlap (primary branch): tree / peer-layout / snowflake → `structure-survey`; ownership/depth → `deep-modules`; type dual homes → `refactor-types`; serialize/layer shells → `refactor-boundaries`; measured speed/alloc → `performance`; named GoF / which-pattern → `design-patterns`.
5. Growth default: stage in [`learning-log.md`](learning-log.md) → **sparse-promote** into the matching `reference/<branch>.md` Checklist or Anti-patterns only when judgment changes and neither that file nor [`glossary.md`](glossary.md) covers it → **drop** the rest. Edit the router only when the contract is wrong.
