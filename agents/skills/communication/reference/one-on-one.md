# One-on-One

Raw 1:1 notes (markdown, blockquotes, shorthand, `Q:`/`A:`/`q:` markers) → post-meeting summary the note taker sends to the other person so both can verify what was said.

## Output

- Two-person voice: **I** = note taker, **You** = other person; both must recognize themselves.
- One flat bullet list, one bullet per question/topic, no grouped sections. Drop nothing substantive; merge only fragments that restate the same point.
- Bullets typically open with the note taker's action ("I asked about X.") then the response. Keep the note taker's own remarks as "I …".
- Other person: "You: …" for multi-part answers; woven prose ("You'll …", "You want …") for single points.
- Keep unresolved questions, concerns, commitments, and process friction inline; no editorializing or invented certainty.
- Fix shorthand and typos in ordinary words only; carry proper nouns, ticket IDs, and codenames verbatim.

## Steno notation

- Any line whose marker chain contains `>` → other person (**You**). Lines without `>` — including `-` sub-points — → note taker (**I**).
- `> Q:` = other person asked; bare `Q:`/`q:` = note taker asked. `A:` = note taker's answer; `> A:` = other person's.
- Indented follow-ups belong to the item above.
- Unclear attribution → "we discussed X".

## Example

```markdown
Q: noshow on quarterly sync?
> took part in the beginning
> catched up via notes
- tickets are high level, align before work
```

→ I asked about the no-show. You took part at the beginning and caught up via notes. I noted tickets are high-level, so align before work.
