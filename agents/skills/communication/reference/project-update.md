# Project Update

Project notes, status reports, meeting outcomes, Jira updates → one update comparable across projects.

`<Project> | <Status> | <Progress> | <Risk/Blocker> | <Next>`

Status: `🟢 On Track` | `🟡 Attention Needed` | `🔴 At Risk`

- ≤200 characters unless asked for longer.
- Outcomes over activities; plain business language; concrete numbers when they aid scanning.
- Keep status, key progress, the single most decision-relevant blocker, and the next milestone. Missing element → infer cautiously.
- Keep the input's project name.
- Real progress but a policy or dependency threatens the next milestone → `🟡`, not `🟢`.
- Blocker phrasing: operational, system-first, neutral.
