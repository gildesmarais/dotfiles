# Project Update

Project notes, status reports, meeting outcomes, Jira updates → one short update comparable across projects.

## Required format

`<Project> | <Status> | <Progress> | <Risk/Blocker> | <Next>`

Status: `🟢 On Track` | `🟡 Attention Needed` | `🔴 At Risk`

## Rules

- ≤200 characters unless the user asks for longer.
- Outcomes over activities; no implementation detail; plain business language; concrete numbers when they aid scanning.
- Keep only status, key progress, the single most decision-relevant blocker, and the next meaningful milestone. Missing element → infer cautiously.
- Use the input's project name unless asked to rename.
- Real progress but a policy or dependency threatens the next milestone → `🟡 Attention Needed`, not `🟢 On Track`.
- Blocker phrasing is operational and system-first; neutral tone — no diplomacy or persuasion.
